# Task 5: Deploy a Static Website Using GitHub Pages

## Objective

Host a static website on GitHub Pages and make it accessible through a public URL.

## Project Overview

This project demonstrates how to deploy a responsive static website using GitHub Pages. The website is built using HTML, CSS, and JavaScript and is hosted directly from a GitHub repository.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

## Features

* Responsive web design
* Interactive user interface
* Fast and free hosting using GitHub Pages
* Publicly accessible website

## Repository Link

https://github.com/Nimisha-Budati/Nimisha-Budati.github.io

## Live Website

https://nimisha-budati.github.io/

## Deployment Steps

1. Created a GitHub repository named `Nimisha-Budati.github.io`
2. Added website files to the repository
3. Committed and pushed the code to GitHub
4. Enabled GitHub Pages from the repository settings
5. Selected the `main` branch as the deployment source
6. Accessed the live website through the GitHub Pages URL

## Learning Outcomes

* Understanding Git version control
* Managing repositories on GitHub
* Hosting static websites for free
* Deploying projects using GitHub Pages
* Understanding the deployment workflow
